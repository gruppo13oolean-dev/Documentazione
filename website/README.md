# 13oolean — Documentazione di progetto (Next.js)

Sito documentale del gruppo **13oolean** (Università degli Studi di Padova), convertito interamente in **Next.js (App Router)** con Tailwind CSS v4.

## Sviluppo locale

```sh
npm install
npm run dev
```

## Build di produzione

```sh
npm run build
npm run start
```
